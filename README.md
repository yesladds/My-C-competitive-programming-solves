# My C++ Competitive Programming Journey
## About This Repository
Hello! I am Lakshay, a Secondary 4 student from Singapore with a strong interest in programming, problem-solving and Information Technology.
This repository documents my progress in learning C++ through competitive programming exercises and challenges on Codebreaker. It contains solutions that I completed while developing my understanding of programming fundamentals, algorithms and structured problem-solving.
My aim is not only to obtain the correct output, but also to understand why each solution works and how it can be improved.
---
## Why I Created This Repository
I created this repository to:
- Document my progress in C++
- Organise the programming problems I have solved
- Practise writing clear and efficient code
- Strengthen my logical and analytical thinking
- Learn how to use GitHub and version control
- Build a portfolio that demonstrates my interest in IT
Each problem has helped me become more confident in breaking a larger task into smaller steps and translating my reasoning into code.
---
## Concepts Practised
The solutions in this repository involve concepts such as:

- Variables and data types
- Input and output
- Arithmetic and logical operators
- Conditional statements
- For and while loops
- Functions
- Strings and arrays
- Vectors
- Sorting
- Searching
- Brute-force approaches
- Greedy problem-solving

## What I Have Learnt
Working on these problems has taught me that programming often requires more than knowing syntax. I need to understand the requirements, identify patterns, consider different approaches and test whether my solution handles different inputs correctly.
I have also learnt that mistakes and unsuccessful attempts are an important part of the learning process. Debugging my programs has improved my attention to detail and helped me understand C++ more deeply.
